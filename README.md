# 🎲 Ludo Game

A classic 4-player Ludo board game built with vanilla HTML, CSS, and JavaScript. No build step required — just open `index.html` in a browser or host on GitHub Pages!

## How to Play

1. **Roll the dice** — click the dice or the "Roll Dice" button on your turn.
2. **Bring tokens out** — roll a 6 to move a token from home onto the start cell.
3. **Move clockwise** — tokens travel around the main path.
4. **Capture** — land on an opponent's token to send it back home.
5. **Safe cells** — the ⭐ cells are safe from capture.
6. **Home stretch** — enter the colored path leading to the center.
7. **Win** — be the first to get all 4 tokens to the center.

## Features

- 4-player support (Red, Green, Yellow, Blue)
- Dice rolling animation
- Token capture mechanics
- Safe zones on the board
- Roll-a-6 for an extra turn
- Beautiful dark theme with gradient accents
- Responsive design

## Run Locally

Just open `index.html` in your browser.
